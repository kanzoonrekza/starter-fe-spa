# AGENTS.md

React 19 + Vite SPA starter. pnpm only (see `pnpm-lock.yaml`).

## Commands

- `pnpm dev` — dev server
- `pnpm build` — `tsc -b && vite build`. **This is also the typecheck**; there is no separate typecheck script.
- `pnpm lint` / `pnpm format`
- No test runner is installed. Don't invent `pnpm test`; verify with `pnpm lint && pnpm build`.

## Gotchas

- `src/routeTree.gen.ts` is generated by the `@tanstack/router-plugin` vite plugin. Never edit it; it regenerates on dev/build when files under `src/routes/` change.
- UI is **shadcn on `@base-ui/react`** (style `base-nova`), not Radix. Composition uses `render={<Link to="/" />}`, not `asChild`. Add components with `pnpm dlx shadcn@latest add <name>`.
- `cn` comes from the `cn` npm package; `src/lib/utils.ts` is just a re-export.
- Tailwind v4 via `@tailwindcss/vite`. There is no `tailwind.config.*` — theme lives in `@theme inline` inside `src/index.css`.
- React Compiler is enabled (`babel-plugin-react-compiler` via `@rolldown/plugin-babel`). Skip manual `useMemo`/`useCallback` unless there's a measured reason.
- `tsconfig.app.json` sets `noUnusedLocals`, `noUnusedParameters`, `erasableSyntaxOnly`, `verbatimModuleSyntax` — use `import type` for types; no TS enums/parameter properties.
- Prettier: no semicolons, double quotes, `prettier-plugin-tailwindcss` sorts class names. Run `pnpm format` before finishing.
- `src/routes/**/*.tsx` is exempt from `react-refresh/only-export-components` (route files export `Route`).

## Layout

- `src/routes/` — file-based routes; `__root.tsx` holds layout, 404, and error boundary.
- `src/api/client.ts` — axios instance on `VITE_API_URL` (only env var; see `.env.example`).
- `src/api/query-client.ts` — shared QueryClient; `shouldRetry` deliberately skips retries on 4xx.
- `@/*` aliases `src/*` (set in both `vite.config.ts` and `tsconfig.app.json` — update both if changed).
